
# KNIME Sales Analytics Capstone Project

## Project Overview
This project focuses on analyzing sales data using KNIME Analytics Platform. It includes data cleaning, data integration, KPI calculation, visualization, and business insights.

## Datasets
The project uses four datasets:
- Orders.csv
- Customers.csv
- Products.csv
- Returns.csv

## Tools and Technologies
- KNIME Analytics Platform
- CSV Datasets
- Data Cleaning and Transformation
- Data Visualization
- Graph Theory and Route Optimization (if included in the final workflow)

## Project Workflow
1. Import datasets
2. Identify and handle missing values
3. Remove duplicate records
4. Transform date and other columns
5. Integrate datasets using Joiner
6. Calculate key performance indicators (KPIs)
7. Create visualizations
8. Analyze sales performance

## Repository Structure
- Datasets/ – Source CSV files
- KNIME_Workflow/ – Exported KNIME workflow
- Screenshots/ – Project screenshots
- Project_Report.pdf – Final project report
